# ⏱️ Premium Stopwatch Web App

A modern, responsive stopwatch built using **HTML, CSS, and JavaScript**, featuring a premium dark theme, glassmorphism design, colorful controls, and lap-time tracking.

## 🌐 Live Demo

**[Click here to use the Stopwatch](https://mohitsolanki721.github.io/stopwatch-web-app/)**

## ✨ Features

- ▶️ **Start:** Start measuring elapsed time.
- ⏸️ **Pause:** Pause the running stopwatch.
- 🔄 **Reset:** Reset the timer and clear recorded laps.
- 🏁 **Lap Tracking:** Record lap times while the stopwatch runs.
- 🎨 **Premium UI:** Dark navy background, glass-style interface, and blue-purple gradients.
- 📱 **Responsive Design:** Designed to work across different screen sizes.
- ⚡ **Lightweight:** Built with vanilla HTML, CSS, and JavaScript without a framework.

## 🛠️ Technologies Used

- **HTML5** — Structure and stopwatch controls.
- **CSS3** — Styling, gradients, glassmorphism, and responsive layout.
- **JavaScript** — Timer logic, button interactions, and lap tracking.
- **Git & GitHub** — Version control and source-code hosting.
- **GitHub Pages** — Website deployment.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MohitSolanki721/stopwatch-web-app.git
   ```

2. Open the project folder:

   ```bash
   cd stopwatch-web-app
   ```

3. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

## 🚀 Deployment

This project is hosted using GitHub Pages.

To configure deployment for your own copy:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Save your settings and wait for deployment.
